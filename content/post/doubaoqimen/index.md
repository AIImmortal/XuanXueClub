## 第二步：把排盘结果 + 占问事项发给豆包

排盘只是第一步，真正有价值的是解读。而解读的质量，取决于你**怎么问**。

### 2.1 占问事项怎么写才有效

奇门遁甲讲究"无事不占"，问题越具体，解读越精准。对照下面的写法：

| ❌ 太宽泛 | ✅ 具体有效 |
|-----------|-------------|
| 我今年运势怎么样？ | 我今年Q4换工作的话，能不能找到比现在薪资高20%以上的岗位？ |
| 我和他合适吗？ | 我和相亲对象认识三个月，他最近比较冷淡，我们还能继续发展吗？ |
| 这个生意能做吗？ | 我打算投资50万开一家社区咖啡店，位置在XX小区门口，能盈利吗？ |
| 我什么时候能结婚？ | 我现在有一个交往半年的对象，我们今年内能订婚吗？ |

**原则：一件事一问，时间、对象、具体选择都写清楚。**

### 2.2 拿到解读后，如何继续追问

豆包给出第一轮解读后，不要停在那里。奇门遁甲的盘面信息量大，第一轮往往只是概览，**追问才能挖深**。

以下是几类高效追问方向：

**追问细节**
```
你刚才提到代表我的日干落宫逢空亡，能具体解释一下这意味着什么吗？对我问的这件事有什么实际影响？
```

**追问时间**
```
如果这件事能成，盘面有没有提示大概在什么时间节点？（看马星、冲合、时令）
```

**追问对策**
```
盘面显示这件事有阻碍，主要阻碍来自哪里？我应该从哪个方向去化解或推进？
```

**追问选择对比**
```
我现在有两个选择：A方案和B方案。从这个盘面看，哪个更有利？分别代表什么符号？
```

**追问应期**
```
你判断此事可成，那应期大概在什么时候？请结合干支和宫位推算。
```

**追问风险**
```
这个盘面有没有什么隐藏的风险或需要特别注意的地方？比如螣蛇、白虎、玄武所在的宫位对我有什么影响？
```
